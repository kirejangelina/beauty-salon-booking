# UML Диаграммы вариантов использования

Диаграммы показывают, кто пользуется системой Beauty Booking и что он может делать. Названия действий совпадают с разделами бизнес-требований.

## 1. Общая диаграмма системы

Показывает всех акторов (Клиент, Мастер, Администратор) и их основные действия.

flowchart LR
    C["👤 Клиент"]
    M["👤 Мастер"]
    A["👤 Администратор"]

    subgraph SYS["Beauty Booking"]
        U1(["Зарегистрироваться и войти"])
        U2(["Посмотреть услуги и мастеров"])
        U3(["Посмотреть свободное время"])
        U4(["Записаться на услугу"])
        U5(["Посмотреть/отменить свои записи"])
        U6(["Посмотреть своё расписание"])
        U7(["Отметить результат визита"])
        U8(["Управлять услугами и мастерами"])
        U9(["Посмотреть отчёты"])
    end

    C --- U1
    C --- U2
    C --- U3
    C --- U4
